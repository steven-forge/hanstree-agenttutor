## 검토 방법과 범위

운영 사이트의 주요 메뉴 8개와 대표 하위 페이지를 실제 운영 주소로 열고, 메뉴 이동·페이지 이동·릴리스 제품 탭·뉴스 2페이지·공식 원문 링크 구조를 확인했습니다. 모든 확인 경로는 HTTP 200으로 응답했습니다.

현재 작업 환경에는 화면을 픽셀 단위로 확인할 GUI 브라우저가 없어, 운영 HTML에 실제 표시된 제목·설명·목록·링크·상태를 중심으로 평가했습니다. 따라서 모바일에서의 실제 손가락 조작성, 글자 잘림, 스크롤 체감은 이번 점수에 포함하지 않았습니다.

## 공통 평가 기준

### 1. AI 초보자용 학습 로드맵 — 8/10

Learn에는 6단계 기초 과정과 12개 작동 방식 주제가 있어 학습 순서 자체는 명확합니다. 하지만 Overview에서 Learn의 첫 단계로 바로 안내하는 주 행동이 없고, Learn 안에서도 두 묶음의 권장 선후 관계가 분명하지 않습니다.

가장 먼저 할 일은 새 기능을 늘리는 것이 아니라 Overview와 Learn 상단에 하나의 추천 시작 경로를 명시하는 것입니다.

### 2. 쉬운 AI 용어 안내 — 8/10

용어사전과 Learn 상세 문서의 비유·예시가 서로 연결되어 있어 대부분의 핵심 개념을 쉽게 풀어줍니다. 반면 Agent Engineering과 CLI Docs에서는 전문 용어가 설명보다 먼저 등장하고, 새 작동 방식 과정의 일부 용어는 용어사전에 아직 없습니다.

용어를 새로 설명하는 별도 체계보다 기존 Glossary에 누락 항목을 추가하고 모든 전문 용어를 해당 정의로 연결하는 방법이 가장 단순합니다.

### 3. 최신 AI 정보 탐색 — 8/10

AI Newsletter와 Releases가 분리되어 있고, 발행 시각·공식 출처·한국어 설명·수집 상태가 표시되어 신뢰할 근거가 충분합니다. 다만 누적된 항목이 많아질수록 페이지 번호만으로 원하는 소식을 찾기 어렵고, 기술 릴리스는 초보자에게 필요한 변화인지 빠르게 구분하기 어렵습니다.

우선순위는 새 수집원을 늘리는 것보다 출처·주제 필터와 `초보자에게 미치는 영향` 요약을 강화하는 것입니다.

## 개선 우선순위

1. Overview에 초보자용 단일 시작 버튼 추가
2. Learn의 두 학습 묶음에 권장 순서 표시
3. Newsletter에 출처 또는 주제 필터 추가
4. Releases에서 빈 변경 구역 축소와 대상 사용자 안내
5. 새 학습 용어를 Glossary에 연결
