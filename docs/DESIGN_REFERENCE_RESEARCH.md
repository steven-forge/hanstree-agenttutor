# 디자인·레이아웃 참고 사이트 조사

- 조사일: 2026-09-22
- 조사 목적: AI 초보자가 `무엇부터 배울지`, `낯선 용어를 어디서 풀어볼지`, `최신 정보를 어떻게 좁혀볼지` 쉽게 판단할 수 있는 화면 구조 찾기
- 적용 대상: Hanstree AgentTutor의 Overview, Learn, Glossary, AI Newsletter, Releases

## 조사 기준

1. 첫 방문자가 다음 행동을 바로 선택할 수 있는가
2. 학습 순서·난이도·예상 시간이 드러나는가
3. 전문 용어를 쉬운 설명과 관련 콘텐츠로 연결하는가
4. 최신 콘텐츠의 날짜·주제·종류를 빠르게 비교할 수 있는가
5. AgentTutor의 기존 콘텐츠 구조에 큰 재작성 없이 적용할 수 있는가

이번 문서는 공개 페이지에서 실제로 확인한 정보 구조를 비교한 조사 보고서입니다. 디자인과 레이아웃은 수정하지 않았습니다.

## 사이트별 분석

### 1. Microsoft Learn — AI Fluency

- 직접 확인: [AI Fluency 학습 경로](https://learn.microsoft.com/en-us/training/paths/ai-fluency/)
- 참고할 요소: 화면 위에서 `Beginner`, 학습 경로, 7개 모듈, 대상 역할을 먼저 보여주고, 아래에는 기초 AI부터 책임 있는 AI와 실제 활용까지 순서대로 배치합니다.
- 선택 이유: 초보자가 시작 전에 자신의 수준과 학습 범위를 확인할 수 있고, 긴 과정을 모듈 단위로 나눠 부담을 줄입니다.
- AgentTutor 적용: Learn 상단에 `초급`, 전체 단계 수, 예상 시간을 표시하고 각 카드에 순서와 완료 상태를 함께 둡니다. Agent Engineering에는 `Learn 기초 과정 이후 권장`이라는 선수 과정 안내를 붙일 수 있습니다.
- 주의할 점: 역할·제품 필터를 너무 많이 복제하면 오히려 복잡해집니다. AgentTutor에는 `처음 배우기`, `업무에 쓰기`, `도구 만들기` 정도의 최소 분류가 적당합니다.

### 2. Google for Developers — Machine Learning Crash Course

- 직접 확인: [Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)
- 참고할 요소: 첫 화면의 행동을 `과정 시작`, `모듈 둘러보기`, `선수 지식 확인`으로 분리합니다. 처음 배우는 사람에게는 표시 순서를 따르라고 안내하면서, 경험자는 독립 모듈로 바로 이동할 수 있게 합니다. 모듈은 모델·데이터·고급 모델·실전처럼 큰 주제별로 묶습니다.
- 선택 이유: 초보자용 순서와 숙련자용 빠른 이동을 한 화면에서 충돌 없이 제공합니다.
- AgentTutor 적용: Overview의 단일 시작 버튼은 Learn 1단계로 연결하고, 그 옆에는 작은 `전체 과정 보기` 링크만 둡니다. Learn의 두 묶음에는 권장 순서를 명시하되, 각 상세 문서 직접 이동도 유지합니다.
- 주의할 점: Google 과정은 개발 학습 중심이므로 기술 난이도나 전문 용어 표현을 그대로 가져오지 않습니다.

### 3. Claude Academy — Collaborating with AI

- 직접 확인: [Collaborating with AI 컬렉션](https://academy.claude.com/collections/collaborating-with-ai)
- 참고할 요소: `Start here`를 가장 먼저 두고, 그 아래에서 빌더·창작자·교육자·비영리·소상공인·학생처럼 대상별 판을 선택하게 합니다. 각 카드에 과정·튜토리얼 구분, 수업 수, 퀴즈 수, 예상 시간을 함께 표시하고 연구 보고서와 추가 자료는 별도 구역으로 나눕니다.
- 선택 이유: 핵심 입문 경로, 사용자별 경로, 참고 자료가 한 페이지에 있어도 역할이 섞이지 않습니다.
- AgentTutor 적용: Learn 첫 화면을 `처음 시작`, `AI 작동 방식`, `더 깊게 보기`의 세 구역으로 정리할 수 있습니다. 카드에는 `읽기 5분`, `실습 있음`처럼 초보자가 투자 시간을 판단할 최소 정보만 추가합니다.
- 주의할 점: 사용자 유형별로 별도 과정을 만드는 것은 현재 콘텐츠 규모에 비해 큽니다. 우선은 같은 문서에 추천 대상 표지만 붙이는 편이 낫습니다.

### 4. IBM Think — 2026 Guide to AI

- 직접 확인: [The 2026 IBM Guide to AI](https://www.ibm.com/think/topics/ai-guide), [IBM Think Topics](https://www.ibm.com/think/topics)
- 참고할 요소: `Get started`에서 AI·머신러닝·AI 에이전트의 기본 설명으로 시작한 뒤 책임 있는 AI, 프롬프트, 활용 사례 같은 심화 묶음으로 확장합니다. 개별 주제는 쉬운 정의에서 출발해 관련 개념과 다른 가이드로 연결됩니다.
- 선택 이유: 용어사전을 단순 가나다 목록이 아니라 학습의 입구로 사용합니다. 초보자는 큰 개념부터 읽고 관련 용어로 자연스럽게 이동할 수 있습니다.
- AgentTutor 적용: Glossary 상단에 `먼저 알아둘 6개 용어`를 두고, 각 항목 아래에 관련 Learn 문서 한 개와 다음 용어 한 개를 연결합니다. 새 과정의 환각·아첨 성향·편향·파라메트릭 메모리도 독립 항목으로 보강할 수 있습니다.
- 주의할 점: IBM의 긴 설명문을 따라가기보다 AgentTutor의 짧은 정의·예시 형식을 유지하는 것이 좋습니다.

### 5. OpenAI Academy — Content

- 직접 확인: [OpenAI Academy 콘텐츠](https://academy.openai.com/public/content)
- 참고할 요소: Foundations, General Learners, Education, Work, Developers 같은 주제를 먼저 고르고, `Latest`와 `Popular`, 태그, 콘텐츠 형식으로 다시 좁힐 수 있습니다. 짧은 영상에는 재생 시간이 표시되고, 초보자용 콘텐츠는 첫 질문처럼 아주 작은 성공 행동부터 시작합니다.
- 선택 이유: 콘텐츠 수가 많아져도 사용자가 목적과 형식으로 좁힐 수 있어 최신 자료와 기초 자료가 한 목록에서 섞이는 문제를 줄입니다.
- AgentTutor 적용: AI Newsletter에는 우선 `출처` 또는 `주제` 중 하나의 필터만 추가하고, Learn 카드에는 읽기·영상 같은 형식 표지를 붙일 수 있습니다. 필터는 기존 Releases 탭과 같은 조작 방식을 재사용하는 것이 일관적입니다.
- 주의할 점: 많은 주제 태그를 한꺼번에 노출하면 현재보다 탐색이 어려워집니다. 실제 콘텐츠가 충분한 분류만 보여줘야 합니다.

### 6. Anthropic — Newsroom

- 직접 확인: [Anthropic Newsroom](https://www.anthropic.com/news)
- 참고할 요소: 위쪽에는 중요한 소식을 큰 카드와 요약으로 강조하고, 아래에는 검색창과 `날짜·분류·제목` 중심의 조밀한 목록을 둡니다. 훑어보기와 정확한 항목 찾기를 서로 다른 밀도로 해결합니다.
- 선택 이유: 최신 소식의 중요도와 시간순 탐색을 동시에 제공합니다. 카드만 계속 이어지는 목록보다 오래된 자료를 찾기 쉽습니다.
- AgentTutor 적용: AI Newsletter 위쪽에는 최신 또는 중요 글 1~3개만 강조하고, 나머지는 날짜·출처·주제가 잘 보이는 간결한 목록으로 유지합니다. Releases에도 제품 탭 아래에 같은 정보 밀도 원칙을 적용할 수 있습니다.
- 주의할 점: 한 회사의 뉴스룸은 자사 소식만 다룹니다. AgentTutor는 현재처럼 여러 공식 출처를 유지하고, `공식 발표`와 `편집 해설`을 구분해야 합니다.

## AgentTutor에 적용할 공통 원칙

### 1. 첫 행동은 하나만 크게 보여준다

Overview의 주 행동은 `AI가 처음이라면 여기서 시작` 하나로 두고 Learn 1단계로 연결합니다. 전체 메뉴와 심화 과정은 보조 링크로 남겨 선택 부담을 줄입니다.

### 2. 학습 카드에는 판단에 필요한 정보만 붙인다

각 과정에 순서, 난이도, 예상 시간, 추천 대상을 표시합니다. 새 분류 체계를 만드는 대신 현재 JSON 데이터에 필요한 항목만 더하는 방식이 적합합니다.

### 3. 기초 경로와 참고 자료를 시각적으로 분리한다

Learn에서는 `처음 시작`과 `AI 작동 방식`의 선후 관계를 먼저 보여주고, Agent Engineering과 CLI Docs는 `심화·참고` 구역으로 분리합니다.

### 4. 용어는 사전에서 끝내지 않고 학습으로 연결한다

Glossary 항목마다 쉬운 정의, 짧은 예시, 관련 Learn 문서, 다음에 볼 용어를 한 묶음으로 제공합니다. 별도의 새 용어 시스템은 만들지 않습니다.

### 5. 최신 정보는 강조 영역과 탐색 목록을 나눈다

상단에는 중요한 최신 항목만 강조하고, 아래에는 검색 또는 하나의 필터와 조밀한 목록을 둡니다. 뉴스와 릴리스 모두 날짜·출처·대상 사용자가 먼저 보이게 합니다.

## 개편 우선순위 제안

1. Overview에 초보자용 단일 시작 행동 추가
2. Learn에 두 과정의 권장 순서와 난이도·예상 시간 표시
3. Glossary의 핵심 입문 용어 묶음과 Learn 상호 링크 추가
4. AI Newsletter에 한 종류의 필터와 상단 중요 소식 구역 추가
5. Releases에 대상 사용자 한 줄과 빈 변경 구역 축소

이 순서는 기존 콘텐츠를 재사용하면서 초보자의 선택 부담을 먼저 줄이는 기준입니다. 실제 화면 개편 전에는 모바일·데스크톱 시안을 함께 만들고, 운영 콘텐츠 길이로 카드 높이와 목록 밀도를 확인해야 합니다.
