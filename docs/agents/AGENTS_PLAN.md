# Agents 개발 계획

## 목표

주요 AI Agent 제품의 특징과 사용 맥락을 비교해, 사용자가 어떤 도구를 선택할지 이해하도록 돕는다.

## 메뉴

- Claude
- Codex
- Gemini
- Grok

## 문서 구성

모든 Agent 문서는 같은 항목으로 비교한다.

- 한줄 소개
- 잘하는 일
- 작업 방식과 강점
- 적합한 사용자와 상황
- 주의할 점
- 공식 문서·홈페이지
- 다른 Agent와의 차이

## 원칙

- 특정 제품을 근거 없이 우월하다고 표현하지 않는다.
- 변할 수 있는 모델명·가격·지원 기능은 확인 날짜와 출처를 함께 둔다.
- 공개적으로 확인 가능한 정보와 해석을 구분한다.
- 비교는 기능 나열보다 실제 선택 상황 중심으로 작성한다.

## 데이터 출처·수집 방식

- Claude, Codex, Gemini, Grok 각각의 공식 홈페이지·공식 문서·공식 발표를 1차 출처로 사용한다.
- 모델명, 가격, 지원 기능, 사용 제한처럼 변할 수 있는 정보는 공식 페이지에서 확인한다.
- 정해진 갱신 시점에 공식 출처의 공개 페이지와 RSS·API가 있으면 이를 확인하고, 없으면 수동 검토한다.
- 제품별 원문 URL, 확인 날짜, 적용 시점, 확인한 내용을 데이터에 함께 저장한다.
- 비교 문장과 적합한 사용 상황은 확인된 사실을 바탕으로 편집하며, 추정은 사실처럼 표시하지 않는다.
- 출처 변경이나 확인 실패 시 기존 내용을 삭제하지 않고 오래된 정보 또는 확인 필요 상태로 표시한다.

## 완료 기준

- 4개 Agent 문서가 같은 기준으로 비교된다.
- 각 문서에 공식 출처와 확인 날짜가 있다.
- 최신성이 필요한 정보의 갱신 책임이 정해져 있다.
- 사용자가 자신의 목적에 맞는 선택을 할 수 있다.
