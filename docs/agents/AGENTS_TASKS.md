## 완료 확인

- 2026-09-20, v0.2.0: 제품 소개 4개, App·CLI·API 비교, 공식 출처·검토일·갱신일 및 재확인 안내 구현 및 운영 경로 응답을 확인했다.
- 전체 31개 운영 경로 HTTP 200. 로컬 빌드 및 문서 ID·용어 연결 자체 점검 통과. 대표 화면은 390·768·1280px에서 가로 넘침 없이 표시됐다.
- OpenAI 공식 시작 문서로 데스크톱 앱의 Codex 선택 경로를 확인하고, Grok 공식 CLI 제공 사실을 반영했다. 추천 상황은 편집자의 활용 예시이며 가격·성능 순위를 제공하지 않는다.

- 2026-09-21: 후보 발견 방식을 Gemini 공개 웹 조사로 전환했다. 외부 후보 자동 수집은 사용하지 않으며, 편집자가 공식 URL을 확인한 후보만 비교 목록에 반영한다. 목록 화면은 Artificial Analysis의 밀도 높은 목록형 구성을 참고한다.
