# Agent 후보 조사 초안 템플릿

Gemini 공개 웹 조사 결과를 바탕으로 신규 AI Agent 후보를 발굴하고 검토·승인하기 위한 공통 Markdown 초안 서식입니다.

> [!IMPORTANT]
> **공개 데이터 반영 원칙**: 승인 전 후보는 공개 데이터(`data/agents.json`, `/agents`, `/agents/[slug]`)에 절대 등록하지 않습니다. 반드시 `Gemini 제안 → 편집 검토 → 공개 승인`의 모든 단계를 거쳐 공식 확인된 정보만 공개 데이터에 반영합니다.

---

## 1. 진행 상태 추적 (Workflow Status)

후보 검토 상태는 아래 3단계를 순차적으로 진행하며, 각 단계의 담당자, 일시, 메모를 기록합니다.

| 단계 | 상태 | 담당자 | 일시 (KST) | 검토 메모 및 근거 |
| :--- | :--- | :--- | :--- | :--- |
| **1단계: Gemini 제안** | `[대기 / 완료]` | Gemini (공개 웹 조사) | YYYY-MM-DD HH:mm | 제안 배경, 조사 질문, 릴리스 감지 요약 |
| **2단계: 편집 검토** | `[대기 / 진행중 / 반려 / 통과]` | 편집자 이름 | YYYY-MM-DD HH:mm | 공식 URL 접속 확인, 제공 형태·도구 방식 사실 검증, 반려 시 사유 |
| **3단계: 공개 승인** | `[대기 / 승인 / 보류]` | 최종 승인자 | YYYY-MM-DD HH:mm | data/agents.json 반영 승인, 슬러그 및 문서 연결 확인 |

- **현재 진행 상태**: `Gemini 제안` (초안 작성 시 기본값)
- **최종 판정**: `승인 대기` (공개 승인 완료 전까지 공개 배포 금지)

---

## 2. 후보 기본 정보 (Candidate Profile)

| 항목 | 내용 | 작성 지침 |
| :--- | :--- | :--- |
| **후보명 (Title)** |  | 공식 제품 명칭 (예: Claude, Codex, Gemini, Grok) |
| **식별자 (ID / Slug)** |  | 영문 소문자 케밥 케이스 (URL 경로로 사용됨, 예: cursor, windsurf) |
| **개발사 (Provider)** |  | 공식 개발사 또는 조직명 (예: Anthropic, OpenAI, Google, xAI) |
| **목적 및 한줄 소개 (Tagline)** |  | 제품의 핵심 기능 및 사용 목적 한줄 요약 (마케팅 문구 배제) |
| **확인일 (Reviewed Date)** | YYYY-MM-DD | 공식 원문 자료 최종 확인 일자 (KST 기준) |

## 3. 제공 형태 (Form Factors)

공식 출처를 통해 실제 동작 및 제공 여부가 검증된 사실만 기록합니다.

| 형태 | 지원 상태 (`공식지원확인` / `조건부` / `미확인`) | 세부 사항 및 공식 근거 메모 |
| :--- | :--- | :--- |
| **App** |  | 웹 인터페이스, 데스크톱 앱, 모바일 앱 지원 여부 |
| **CLI** |  | 터미널 실행 가능한 공식 커맨드라인 도구 제공 여부 |
| **API** |  | 프로그래밍 방식 접근 인터페이스 (SDK, REST, RPC 등) |

> **상태 판정 기준**:
> - `공식지원확인`: 공식 웹사이트, 공식 릴리스 문서에서 명시적으로 지원이 확인된 경우
> - `조건부`: 특정 환경, 유료 플랜, 프리뷰/베타 단계 또는 제한적 연동만 제공되는 경우
> - `미확인`: 공식 문서에서 명확한 언급이 없거나 검증 대기 중인 경우 (미지원을 의미하지 않음)

---

## 4. 도구 방식 (Tool Modes)

공식 자료로 이미 확인된 도구 연동 방식만 기록하며, 확인되지 않은 지원(특히 IDE)을 임의로 추정하지 않습니다.

| 도구 방식 | 지원 여부 (`확인` / `미확인`) | 공식 근거 및 세부 사양 |
| :--- | :--- | :--- |
| **MCP** |  | Model Context Protocol 서버/클라이언트 연동 지원 여부 |
| **IDE** |  | VS Code, JetBrains 등 IDE 확장/플러그인 공식 제공 여부 (*추정 금지, 미확인 시 미확인 기재*) |
| **Terminal** |  | 터미널 TUI, 대화형 셸, CLI 워크플로우 지원 여부 |

---
