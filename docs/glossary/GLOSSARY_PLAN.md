# Glossary 개발 계획

## 목표

AgentTutor 전체에서 사용하는 AI·Agent 용어를 짧고 일관되게 설명한다.

## 메뉴

- Glossary

## 항목 구성

각 용어는 용어명, 한국어 풀이, 한줄 정의, 쉬운 예시, 관련 용어, 처음 등장하는 학습 문서, 확인한 출처를 가진다.

## 분류

- 기본 개념: Agent, LLM, Prompt, Context, Memory
- 구성 요소: Tool, Skill, Hook, Plugin, MCP
- 구조·운영: Sub Agent, Agent Pattern, Context Management
- 제품·실행: CLI, Command, Model

## 원칙

- 한 용어에 한 핵심 뜻을 우선한다.
- 유사 용어의 차이를 함께 설명한다.
- 번역어와 원어를 함께 표기한다.
- 제품별 의미가 다르면 공통 뜻과 제품별 뜻을 나눈다.

## 데이터 출처·작성 방식

- 용어의 기본 정의는 공식 문서, 공개 표준, 연구 논문 등 확인 가능한 자료에서 가져온다.
- 제품별 용어는 해당 제품의 공식 문서에서 의미와 사용 맥락을 확인한다.
- 용어 데이터는 내부 JSON 또는 문서 데이터로 관리하고, 정의·예시·관련 용어·출처 URL을 함께 저장한다.
- 새 문서 작성 때 Learn과 Agent Engineering에서 처음 사용된 용어를 찾아 등록한다.
- 출처가 변경되면 정의를 바로 덮어쓰지 않고 확인 날짜와 변경 내용을 검토한 뒤 갱신한다.

## 완료 기준

- 주요 메뉴의 핵심 용어가 모두 등록된다.
- 문서 본문에서 Glossary로 이동할 수 있다.
- 중복 정의와 서로 다른 번역이 정리된다.
