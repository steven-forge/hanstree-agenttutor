# Gemini 4 Argon: 장기·다단계 추론에 초점을 둔 모델

- 확인일: 2026-10-02 (KST)
- 참고 출처: https://blog.google/intl/ko-kr/products/gemini-4-argon-kr/ , https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/
- 발표일: 2026-09-30
- 이 문서는 공식 발표 원문을 그대로 옮긴 것이 아니라, 내용을 이해한 뒤 독자적인 설명으로 다시 정리한 것입니다.

## Argon은 무엇인가

Gemini 4 Argon은 Google DeepMind가 내놓은 모델로, 한 번의 질문-답 대신 여러 단계를 이어가는 장기·다단계 깊은 추론에 초점을 둡니다. 공식 발표는 코딩, 기업 문서·차트 분석, 긴 영상 이해, 보안 방어 영역에서의 활용을 강조합니다. 가장 두드러진 변화는 한 번의 응답에서 만들 수 있는 출력이 최대 100만 토큰으로 늘었다는 점이며, 이는 모델이 한 번에 읽어들이는 입력(컨텍스트) 한도와는 다른 수치이므로 혼동하지 않아야 합니다.

## 벤치마크는 공급사 발표 수치

DeepSWE v1.1 77.9%, AutomationBench 51.3%, LVBench 91.7%, CWE-bench v1 68% 같은 수치가 공개됐지만, 모두 공급사가 발표한 자료이며 이 문서에서 독립적으로 재검증한 수치는 아닙니다. 실제 업무에서의 정확도를 보장하지도 않습니다.

## 이용 범위와 가격은 단계적

보안 방어 영역은 신뢰하는 보안 전문가 그룹(Fairwind)에 우선 제공되고, 유료 API와 AI Ultra 요금제로는 순차적으로 넓혀갈 계획입니다. 한국의 모든 계정이 지금 바로 이용할 수 있다고 단정할 근거는 없고, 정확한 API ID나 일반 공개 날짜는 확인하지 못했습니다. 가격은 도입 기간 동안 입력 100만 토큰당 $2, 출력 100만 토큰당 $10이며 캐시 입력은 95% 할인된다고 발표했습니다. 이를 계산하면 100만 캐시 입력 토큰당 $0.10입니다. 도입 기간이 끝나면 입력 $4·출력 $20으로 오른다는 내용이 영문 각주에 있으나, 종료일은 확인하지 못했고 이는 별도의 구독 요금제와 구분됩니다.

## 모델과 에이전트는 다르다

Argon은 모델 자체이며, dots처럼 도구를 다루며 작업을 이어가는 에이전트 제품과는 다른 층입니다. 일반 이용자 모두에게 무제한 출력을 주거나 PC를 자동으로 조작하는 기능이 아닙니다.

## 정리

Argon은 장기 추론과 늘어난 출력 한도가 핵심이지만, 벤치마크는 공급사의 발표 수치로 인용했으며, 접근 범위·가격·공개 일정은 아직 여러 부분이 확인되지 않았습니다. 추가 정보가 공개되면 이 문서를 보완합니다.
