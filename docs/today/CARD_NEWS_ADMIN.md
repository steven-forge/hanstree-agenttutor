# AgentTutor 카드뉴스 관리

관리자 화면 경로: `/admin/news`. 서버 로그인은 `/admin/news?mode=server`.

## 현재 사용 방식

사용자 결정: 인스타그램 계정 연결은 나중에 한다. 관리자가 검토한 뒤 **발행 버튼**으로 게시한다. 09:00 자동 게시는 하지 않는다.

연결 전에도 브라우저 작업 공간에서 후보 수집, 10개 선정, 카드 원고·순서 수정, 출처 확인, 설명 작성, JPG 10장 ZIP 다운로드가 가능하다. 초안은 **이 브라우저의 localStorage**에 저장된다. 기기·브라우저 간 동기화는 없으며 브라우저 데이터 삭제 시 지워진다. JSON 내보내기 또는 ZIP 안의 `draft.json`으로 백업한다. JSON 가져오기는 해당 날짜의 초안으로 복원하며 확인 체크와 승인을 다시 받아야 한다.

1. 날짜를 고르고 **후보 수집 시작**을 누른다.
2. 후보 중 중요도 순으로 서로 다른 뉴스 10개를 고른다. 같은 사건을 다룬 기사 여러 개를 별도 뉴스로 세지 않는다.
3. 원문을 읽고 한국어 제목·본문을 다듬는다. 초안은 피드의 제목·소개를 조판한 것으로, 자동 번역이나 내용 검증이 아니다.
4. 기사별 실제 발행 시각과 수치·조건을 확인하고 확인 체크를 한다.
5. 게시글 설명에 날짜·출처를 넣고 **원고 저장 → 실제 저장본 JPG 보기 → 10개 원고 검토 완료** 순으로 진행한다.
6. **JPG 10장 ZIP 받기**로 이미지·캡션·원문 목록을 받는다. 계정 연결 후에는 연결 계정 이름을 확인하고 발행 버튼으로 실제 게시한다.

## 시간과 수집 기준

- Asia/Seoul 기준 전날 08:00부터 판본일 08:00까지의 24시간 구간. 08:30 검토 준비, 09:00 발행은 운영 목표다.
- 기존 AgentTutor 기사와 국내 AI타임스, OpenAI·Google·NVIDIA 및 기존 외부 피드 11곳을 조회한다. 공개 후보 조회는 15분 캐시한다.
- 날짜만 제공되는 기사는 시간 확인 전까지 검토 완료할 수 없다. 미래 시각, 구간 밖 기사, 중복 URL·제목, 확인하지 않은 카드, 10개 미만·초과, 긴 줄, 2,200자 초과 캡션은 승인할 수 없다.
- 후보 수와 검증 완료 수는 다르다. 원문 URL 중복은 자동 제거하고 사건 단위 중복·중요도·내용은 관리자가 확인한다. 후보 10개 미만은 오류로 표시하며 오래된 기사로 채우지 않는다.
- 2026-10-03 아침판 구간을 최초 조회해 후보 69개를 확인했다. 시간대 없는 기사를 날짜 확인 대상으로 분리한 최종 운영 빌드의 로컬 조회에서는 **89개(정확한 시각 제공 39개·날짜만 확인 50개)**였다. 기존 기사 포함 16개 경로 중 VentureBeat 1곳은 HTTP 429였다. 날짜 확인 대상은 정확한 원문 시각을 관리자가 입력해야 한다. 매일 최소 10건의 검증 완료를 보장한 결과는 아니다.

## 고정 카드 규격

1080 × 1350 JPG, 검정 `#000000`, 네온라임 `#CCFF00`. 상단 `AI News 10`은 126px·굵기 700, AgentTutor 브랜드 유지. 제목 최대 2줄, 본문 최대 6줄. 날짜·출처·뉴스 번호는 카드 안에 표시하지 않는다. 긴 원고를 자동으로 작게 줄이거나 자르지 않고 수정을 요구한다.

폰트는 재배포 가능한 NanumGothic Bold·ExtraBold와 Arial 호환 계열 Arimo를 프로젝트에 포함했다. 라이선스는 `public/fonts/`에 있다. 브라우저 다운로드는 Canvas, 연결 후 서버 JPG는 Next.js ImageResponse와 sharp를 사용한다. 폰트와 여백은 고정했으며 브라우저와 서버의 미세한 글꼴 렌더링 차이가 있을 수 있어 각 저장본 JPG를 확인한다.

## 나중에 서버·인스타그램을 연결할 때

비밀값은 채팅·Git·원고 JSON에 넣지 않는다. 배포 서비스의 보안 환경변수 설정 화면에 운영자가 직접 등록한다. 현재 이 작업에서 계정 연결·비밀값 등록·실제 인스타그램 발행은 하지 않는다.

| 설정 이름 | 용도 |
| --- | --- |
| `CARD_NEWS_ADMIN_PASSWORD` | 관리자 비밀번호, 최소 16자 |
| `CARD_NEWS_SIGNING_SECRET` | JPG 임시 주소 서명용 무작위 비밀값, 최소 32자 |
| `UPSTASH_REDIS_REST_URL` | 전용 Upstash Redis REST HTTPS 주소 |
| `UPSTASH_REDIS_REST_TOKEN` | 위 저장소 접근 권한 |
| `CARD_NEWS_PUBLIC_URL` | 실제 배포된 HTTPS 사이트 주소 |
| `INSTAGRAM_USER_ID` | 연결할 Instagram 프로페셔널 계정 ID |
| `INSTAGRAM_ACCESS_TOKEN` | Instagram Login 방식의 사용자 접근 토큰 |
| `INSTAGRAM_API_VERSION` | 기본 `v26.0`; Meta 지원 버전 확인 후 변경 |
| `CARD_NEWS_CRON_SECRET` | 예약 후보 수집 요청용 무작위 비밀값, 최소 32자 |

Instagram Login 방식으로 연결하며 `instagram_business_basic`, `instagram_business_content_publish` 권한이 필요하다. 개발·검토 단계와 계정 역할에 따른 Meta 권한 준비는 실제 연결 시 확인한다. 자동 OAuth 연결 화면과 토큰 자동 갱신은 포함하지 않는다. 화면의 ‘설정됨’은 환경 설정 존재를 뜻하며 실제 접속 성공을 뜻하지 않는다. 발행 전 계정 확인은 실제 API 응답을 사용한다.

서버 로그인 후 초안과 이력은 Redis에 저장한다. 이 브라우저에 있던 초안은 자동으로 서버에 전송되지 않는다. 현재 서버로 원고 JSON을 가져오는 전용 기능은 없으므로 연결 전 원고를 백업하고 운영 전환 시 이관 범위를 확인한다.

## 예약 수집 준비

`.github/workflows/prepare-card-news.yml`은 KST 08:05·08:20에 **후보만** 수집한다. 인스타그램을 게시하지 않으며 카드 원고 선정·요약·검토도 대신 완료하지 않는다. GitHub 예약 실행은 지연될 수 있어 08:30 정시 완료를 보장하지 않는다.

활성화에는 서버 저장소 설정, GitHub 저장소 변수 `CARD_NEWS_AUTOMATION_ENABLED=true`와 `CARD_NEWS_PUBLIC_URL`, 저장소 비밀값 `CARD_NEWS_CRON_SECRET`이 필요하다. 기본값은 비활성이다. 후보가 10개 미만이면 HTTP 503과 작업 실패를 기록한다. 승인·발행 중인 원고는 덮어쓰지 않는다. 브라우저 작업 공간에서는 창이 닫혀 있을 때 자동 제작되지 않는다.

## 저장과 발행 보호

- 관리자 API는 서버 세션과 요청 출처를 확인한다. 세션은 8시간 만료, HttpOnly·SameSite=Strict, 운영 HTTPS에서 Secure 쿠키를 사용한다. 비밀번호 시도는 15분 동안 20회로 제한한다.
- 저장은 버전 비교와 이력 갱신을 함께 처리한다. 다른 탭에서 먼저 수정했으면 덮어쓰지 않는다.
- 승인 뒤 수정하면 다시 초안으로 돌아간다. 발행이 시작된 원고는 잠근다.
- JPG는 서버 비밀값으로 서명한 24시간 임시 URL로만 Meta에 전달한다. 원고 JSON·토큰·관리자 쿠키는 공개하지 않는다.
- 발행 요청 전에 기록을 저장한다. 응답이 불명확하면 ‘발행 결과 확인 필요’로 남기며 같은 최종 요청을 자동 재전송하지 않는다. ‘발행 계속 및 확인’은 이미지 준비가 끝났고 최종 발행 요청 전인 경우 원래 요청을 이어서 게시한다.
- 인스타그램에서 완료 응답을 받거나 실제 컨테이너의 `PUBLISHED` 상태를 확인했을 때만 ‘발행 완료’로 표시한다.

## 확인 결과 — 2026-10-03 KST

- v0.12.0 `npm run build` 성공, 57개 페이지 생성. 관리자·후보·보호 이미지 경로가 빌드에 포함됐으며 서버 이미지 경로의 배포 추적 목록에 글꼴 4개가 포함된 것을 확인했다.
- 실제 뉴스 후보 조회는 최초 69개, 최종 운영 빌드의 로컬 재조회 89개였다. 화면 점검용임을 명시한 가상 원고로 브라우저 저장 → 검토 → ZIP 다운로드 → 새로고침 → 원고 수정 → 승인 해제 흐름을 확인했다. 두 탭에서 같은 버전을 연 뒤 한쪽이 먼저 저장하면 다른 탭의 낡은 원고 저장이 거절되고 먼저 저장한 원고가 유지되는 것도 확인했다. 실제 뉴스 10건의 내용 검증이나 외부 게시를 수행한 결과는 아니다.
- ZIP의 JPG 10장 모두 1080×1350 JPEG. 캡션·출처·원고 JSON을 포함해 13개 파일이다. 서버 렌더 함수도 실제 기존 카드 원고를 JPG 1080×1350으로 출력했다.
- 1440px 데스크톱과 390px 모바일에서 가로 넘침 없음, 브라우저 실행 오류 없음.
- 비로그인 관리자 조회 401, 외부 Origin 수정 요청 403, 서명 없는 이미지 조회 404, 인증 없는 예약 호출 401 확인.
- 별도 읽기 전용 소스 검토의 5개 지적을 반영했다. 시간대 없는 날짜는 수동 확인 대상, 수정 시각을 발행 시각으로 대체하지 않음, 브라우저 탭 간 Web Locks 사용, 서버 조회 장애 시 로컬 화면 유지, 명시적 인증·권한 거절 시 안전한 발행 복구를 적용했다.
- `npm audit --omit=dev` 취약점 0건. 실제 Redis 연결·Instagram 계정 연결·실게시·예약 활성화는 미실행이다.
- 사용자가 2026-10-04 KST 운영 배포를 직접 승인했다. 배포 대상은 기존 `steven-forge/hanstree-agenttutor` 저장소의 `master`이며 프로젝트 전용 Git 인증과 기존 Vercel 배포 경로를 사용한다. 로컬 빌드 결과만으로 운영 반영을 판정하지 않고 실제 `/admin/news` 응답을 확인한다.
