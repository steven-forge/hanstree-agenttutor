# Today 개발 계획

## 목표

매일 확인할 가치가 있는 AI·Agent 관련 주요 뉴스 10개를 짧고 이해하기 쉽게 제공한다.

## 메뉴

- 오늘의 10대 뉴스

## 핵심 경험

- 날짜와 마지막 갱신 시각 표시
- 순위, 제목, 한줄 요약, 출처, 원문 링크 표시
- 뉴스가 왜 중요한지 초보자도 이해할 수 있게 설명
- 출처 링크는 새 탭에서 열고 원문 우선
- 뉴스가 부족하거나 수집에 실패하면 추측으로 채우지 않고 상태 표시

## 데이터 기준

`date`, `title`, `summary`, `why_it_matters`, `source_name`, `source_url`, `published_at`, `updated_at`

- 한국 시간(KST)을 기준으로 날짜를 구분한다.
- 같은 사건을 반복하거나 광고성 콘텐츠를 우선하지 않는다.
- 확인 가능한 공개 출처만 사용한다.

## 데이터 출처·수집 방식

- AI·Agent 회사의 공식 블로그, 공식 발표, 공식 문서를 1차 출처로 사용한다.
- 주요 기술 매체와 연구기관 자료는 1차 출처를 보완할 때만 사용한다.
- 정해진 시각에 수집기가 출처의 RSS·공개 웹 페이지·공식 API를 확인한다.
- 제목, 발행 시각, 원문 URL을 수집한 뒤 중복 사건을 합치고 중요도 기준으로 10개를 선정한다.
- 수집된 원문을 바탕으로 요약과 중요성을 작성하며, 원문에 없는 사실을 추가하지 않는다.
- 수집 결과는 날짜별 정적 데이터로 저장하고, 원문 URL·수집 시각·갱신 시각을 함께 보존한다.
- 수집 실패 시 마지막 정상 데이터를 임의로 새 뉴스처럼 표시하지 않고 실패 상태를 기록한다.

## 구현 순서

1. 뉴스 목록 데이터 구조 확정
2. 오늘의 10대 뉴스 목록 화면 구현
3. 상세 정보와 출처 링크 연결
4. 날짜·갱신 상태·빈 상태 표시
5. 모바일 화면과 링크 접근성 확인
6. 실제 공개 출처 기준의 갱신 방식 구현

## 완료 기준

- `/today`에서 오늘의 뉴스 메뉴가 열린다.
- 최대 10개 뉴스가 중복 없이 표시된다.
- 모든 뉴스에 출처와 원문 링크가 있다.
- 수집 실패·뉴스 부족 상태를 분명히 알린다.
- 모바일과 데스크톱에서 읽을 수 있다.
