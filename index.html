grok sessions list|search|delete세션 관리세션을 목록 확인·검색·삭제합니다.
grok export 세션ID [출력]대화 내보내기세션 기록을 Markdown으로 저장합니다.
grok import [targets...]세션 가져오기Claude Code 세션을 가져옵니다.
grok memory clear --workspace|--global|--all기억 삭제프로젝트·전체 또는 모든 교차 세션 기억을 지웁니다.
grok worktree list|show|rm|gcGit worktree 관리세션에서 만든 작업공간을 조회·삭제·정리합니다.

5. Grok 화면 안 슬래시 명령

대화형 grok 화면에서 입력합니다.

명령어뜻쉽게 말하면
/quit / /exit종료Grok CLI를 닫습니다.
/help도움말명령과 키보드 단축키를 봅니다.
/home첫 화면환영 화면으로 돌아갑니다.
/new / /clear새 세션새 대화를 시작합니다.
/resume세션 재개이전 세션을 선택해 엽니다.
/sessions세션 목록활성 세션을 전환·이름 변경·종료합니다.
/fork대화 분기현재 세션을 별도 에이전트로 복사합니다.
/rename 이름 / /title이름 변경현재 세션 제목을 바꿉니다.
/share공유세션을 URL로 공유합니다.
/session-info세션 정보현재 세션 정보를 표시합니다.
/context문맥 사용량현재 문맥 사용량을 확인합니다.
/compact [내용]대화 압축대화 기록을 요약해 문맥 공간을 확보합니다.
/rewind되감기이전 턴으로 되돌립니다.
/export내보내기대화를 파일이나 클립보드로 내보냅니다.
/plan [설명]계획 모드계획을 먼저 세우는 모드로 들어갑니다.
/auto자동 승인 모드안전한 도구는 자동 승인하도록 전환합니다.
/always-approve항상 승인 모드도구 승인 질문을 생략합니다. 매우 신중하게 사용하세요.
/create-workflow워크플로우 생성여러 에이전트가 나눠 할 반복 작업을 정의합니다.
/workflow 이름워크플로우 실행저장한 워크플로우를 실행·일시정지·재개·중지합니다.
/workflows워크플로우 대시보드실행 중이거나 보관된 워크플로우를 봅니다.
/deep-research 질문심층 조사웹 검색·출처 확인·요약을 여러 단계로 수행합니다.
